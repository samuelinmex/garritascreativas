PREGUNTAS FRECUENTES

Queremos que pedir algo especial sea sencillo.

Estas respuestas son una base editable. Podemos ajustarlas a la operación real de Garritas antes del lanzamiento.

¿Puedo pedir un diseño completamente personalizado?

Sí. Puedes partir de una creación existente o contarnos una idea desde cero para revisar juntos colores, temática, nombre y detalles.

¿Hacen envíos fuera de Cancún?

Sí, el sitio está preparado para comunicar envíos dentro de México. Antes de publicar definiremos cobertura, costos y tiempos reales.

¿Con cuánto tiempo debo hacer mi pedido?

Como cada pieza se trabaja a mano, recomendamos solicitarla con anticipación. El tiempo exacto se confirmará al cotizar cada proyecto.

¿Cómo se confirma un pedido?

El flujo principal será por WhatsApp: nos cuentas tu idea, definimos detalles, confirmamos cotización y te indicamos el proceso para apartar tu pedido.

¿TIENES UNA IDEA EN MENTE?

No importa si todavía no sabes exactamente cómo quieres que se vea.
